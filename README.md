JavaScript Calculator

A simple calculator built using HTML, CSS, and JavaScript.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero handling
- Clear button to reset the calculator

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Use

1. Open the calculator webpage.
2. Enter two numbers.
3. Select an arithmetic operation.
4. View the result.
5. Click the Clear button to reset the inputs and result.

Project Structure

Learning Objectives

- Understand HTML page structure.
- Apply CSS styling.
- Use JavaScript functions and events.
- Perform basic arithmetic operations.
- Handle invalid inputs.
